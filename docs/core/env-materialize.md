# env-materialize library

## Purpose

Materialize env files when policy requires generating merged output for a service.

## Source files

- `core/lib/env_materialize.sh`

## Inputs and outputs

May write service-specific env output paths configured in manifest (`env_output_file`, `env_materialization`).
