# logger library

## Purpose

Colored ops-branded logging (`ops_info`, `ops_ok`, `ops_error`, `ops_section`, etc.) built on init color constants.

## Source files

- `core/lib/logger.sh`

## Behavior

Respects `OPS_PLAIN` and `OPS_CI` — falls back to plain `[INFO]` style lines.
